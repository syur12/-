## 作り置き

### R01 鶏ハム（レンジ）
**4食分 / P 約34g（1食150g）/ 調理15分＋冷ます時間 / 冷蔵4日**

材料：鶏むね肉 2枚（約600g）、砂糖 小さじ2、塩 小さじ1と1/2、酒 大さじ2

1. むね肉は皮を取り、厚い部分に切り込みを入れて厚さを均一にする。フォークで数か所刺す
2. 砂糖→塩の順にすり込み、ポリ袋で30分〜一晩置く（時間がなければ省略可）
3. 耐熱皿にのせて酒をふり、ふんわりラップ。**1枚あたり600Wで3分→裏返して2分**
4. ラップをしたまま**冷めるまで放置**（余熱で火を通すのがしっとりのコツ）。中心がピンクなら30秒ずつ追加加熱
5. 汁ごと保存容器へ。食べるときに薄切り

> アレンジ：わさび醤油、ポン酢、ゆずこしょう、サラダのトッピング、弁当のメイン

### R02 煮卵
**6個 / P 約6g（1個）/ 調理15分 / 冷蔵4日**

材料：卵 6個、醤油 大さじ4、みりん 大さじ4、水 大さじ4（＝めんつゆ2倍濃縮100mlでも可）

1. 沸騰した湯に冷蔵庫から出したての卵を入れ、**7分（半熟）〜9分（固め）**茹でる
2. 冷水で冷やして殻をむく
3. 調味料を耐熱容器でレンジ1分加熱しアルコールを飛ばし、冷ます
4. ポリ袋に卵と調味液を入れ、空気を抜いて**半日以上**漬ける

### R03 鶏そぼろ
**4食分 / P 約18g（1食100g）/ 調理10分 / 冷蔵4日・冷凍3週間**

材料：鶏ひき肉（むね or もも）400g、醤油 大さじ3、砂糖 大さじ2、みりん 大さじ2、酒 大さじ2、おろし生姜 小さじ1

1. 火をつける前のフライパンに**全材料を入れ、菜箸4本でよく混ぜる**（これでポロポロになる）
2. 中火にかけ、混ぜながら汁気がほぼなくなるまで6〜8分炒り煮する
3. 冷めたら容器へ。ごはん・卵焼き・うどん・野菜炒めの味付けにも使える

### R04 もやしと小松菜のナムル
**3〜4食分 / P 約3g / 調理8分 / 冷蔵3日**

材料：もやし 1袋、小松菜 1/2束（ほうれん草でも可）、ごま油 大さじ1、鶏がらスープの素 小さじ1、塩 少々、白ごま 適量、おろしにんにく 少々

1. 小松菜は4cm長さに切る。耐熱容器にもやし→小松菜を入れ、ラップをしてレンジ4分
2. 水けをしっかり絞る（水っぽさ防止）
3. 調味料をすべて混ぜて和える

### R05 鶏むね肉の下味冷凍（2種）
**各2食分 / P 約33g（1食150g）/ 仕込み10分 / 冷凍1ヶ月**

鶏むね肉を特売で買ったら、皮を取り一口大のそぎ切りにして、ポリ袋に分けて揉み込み冷凍。

| 味 | 鶏むね300gに対して |
|---|---|
| **A 醤油生姜** | 醤油 大さじ1.5、酒 大さじ1、おろし生姜・にんにく 各小さじ1、片栗粉 大さじ1 |
| **B 塩レモン** | 塩 小さじ1/2、酒 大さじ1、レモン汁 大さじ1、こしょう 少々、片栗粉 大さじ1 |

- 使うときは前日に冷蔵庫へ移して解凍 → フライパンで焼くだけ（中火で両面4分ずつ）
- Aは唐揚げ（R15）や照り焼き（R11）、Bはガーリック炒め（R14）にそのまま使える

## 朝ごはん（5分以内）

### R06 納豆卵かけごはん＋豆腐わかめ味噌汁
**P 約22g / 5分**

材料：ごはん 200g、納豆 1パック、卵 1個、醤油 少々 ／ 味噌汁：絹豆腐 50g、乾燥わかめ ひとつまみ、味噌 大さじ1、顆粒だし 小さじ1/3、水 180ml

1. 納豆にタレと卵を混ぜ、ごはんにかける
2. 味噌汁：マグカップに水・だし・わかめ・さいの目豆腐を入れレンジ2分。味噌を溶く

> 時短：味噌汁は「味噌玉」（味噌大さじ1＋だし＋わかめをラップで丸めて冷凍）を作っておくとお湯を注ぐだけ

### R07 オートミール卵雑炊（レンジ）
**P 約22g / 5分**

材料：オートミール 30g、水 150ml、鶏がらスープの素 小さじ1、卵 2個、ツナ缶（水煮）1/2缶、ねぎ 適量

1. 深めの耐熱丼にオートミール・水・鶏がらを入れ、ラップなしでレンジ1分30秒
2. ツナと溶き卵を加えて混ぜ、さらに40秒〜1分（卵が好みの固さになるまで）
3. ねぎ、こしょう、ごま油少々で仕上げ

### R08 ツナ卵丼
**P 約29g / 7分**

材料：ごはん 200g、ツナ缶 1缶、卵 2個、めんつゆ（2倍）大さじ1、ごま油 小さじ1、刻みのり 適量

1. フライパンにごま油を熱し、ツナを汁ごと炒める
2. めんつゆを入れ、溶き卵を回し入れて半熟でごはんにのせる
3. のりをかける

### R09 卵焼き＆鮭おにぎり
**P 約24g / 10分**

卵焼き：卵 2個、砂糖 小さじ1、醤油 少々（または白だし小さじ1）、油 少々
おにぎり：ごはん 200g、鮭フレーク 大さじ2（焼き鮭のほぐし身でも）、のり

1. 卵と調味料を混ぜ、油を引いた卵焼き器で3回に分けて巻く
2. ごはんに鮭を混ぜて2個握る
3. 味噌汁（R06）を添えるとP+5g

### R10 ゆで卵＋豆乳＋バナナセット
**P 約20g / 0分（作り置きのゆで卵 or 煮卵を使用）**

- ゆで卵（または煮卵R02）2個、無調整豆乳 200ml、バナナ 1本
- 時間のない日の最終手段。ソイプロテインを足すとP+15〜20g

## 主菜：鶏肉

### R11 鶏むね肉の照り焼き
**2食分 / P 約33g / 15分**

材料：鶏むね肉 1枚（300g）、片栗粉 大さじ1、塩こしょう 少々、油 大さじ1/2
タレ：醤油・みりん・酒 各大さじ2、砂糖 大さじ1

1. むね肉を1cm厚のそぎ切りにし、塩こしょう→片栗粉をまぶす
2. フライパンに油を熱し、中火で両面を3分ずつ焼く
3. タレを入れ、とろみがつくまで絡める
4. 付け合わせ：キャベツ千切り、ブロッコリー

### R12 鶏むねチキンカレー（ルウなし）
**4食分 / P 約35g / 30分 / 冷凍2週間**

材料：鶏むね肉 2枚（600g）、玉ねぎ 2個、にんじん 1本、トマト缶（カット）1缶、おろしにんにく・生姜 各小さじ2、油 大さじ2、水 200ml
調味料：**カレー粉 大さじ3**、ケチャップ 大さじ3、ウスターソース（中濃）大さじ2、醤油 大さじ1、砂糖 小さじ2、塩 小さじ1、顆粒コンソメ 小さじ2（※乳成分不使用のものを確認）

1. 玉ねぎは薄切り、にんじんは小さめの角切り、むね肉は一口大に切る
2. 鍋に油・にんにく・生姜を入れ、玉ねぎを中火で8分、茶色っぽくなるまで炒める
3. 鶏肉・にんじんを加えて炒め、カレー粉を入れて1分炒める
4. トマト缶・水・残りの調味料を加え、蓋をして弱火15分煮込む
5. とろみが足りなければ水溶き片栗粉で調整

> 市販のカレールウは**乳成分入りが多い**のでこの方法がおすすめ。ゆで卵をトッピングでP+6g

### R13 よだれ鶏（レンジ）
**1食分 / P 約33g / 10分**

材料：鶏むね肉 150g、酒 大さじ1、塩 少々
タレ：醤油 大さじ1、酢 小さじ2、砂糖 小さじ1、ごま油 小さじ1、ラー油 適量、おろしにんにく・生姜 少々、刻みねぎ

1. むね肉に塩・酒をふり、ラップして**レンジ2分→裏返して1分30秒**。そのまま5分放置
2. 薄切りにし、混ぜたタレをかける。もやしや千切りキャベツを下に敷くと野菜もとれる
3. ※作り置きの鶏ハム（R01）を使えば加熱不要

### R14 鶏むねとブロッコリーのガーリック炒め
**1食分 / P 約35g / 12分**

材料：鶏むね肉 150g（R05-Bの下味冷凍でもOK）、冷凍ブロッコリー 100g、にんにく 1片（チューブ小さじ1）、オリーブ油 大さじ1/2、塩こしょう、醤油 小さじ1、片栗粉 小さじ2

1. むね肉はそぎ切りにして塩こしょう・片栗粉をまぶす
2. 油とにんにくを弱火で熱し、香りが出たら鶏肉を中火で焼く
3. 火が通ったらブロッコリーを加えて2分炒め、醤油を鍋肌から回す

### R15 鶏むね唐揚げ（揚げ焼き）
**2食分 / P 約33g / 20分**

材料：鶏むね肉 300g（R05-Aの下味冷凍が便利）、醤油 大さじ1.5、酒 大さじ1、おろし生姜・にんにく 各小さじ1、マヨネーズ 大さじ1（しっとりさせる・卵由来で乳製品ではない）、片栗粉 大さじ4、油 大さじ4

1. 一口大に切ったむね肉に調味料とマヨを揉み込み10分置く
2. 片栗粉をまぶす
3. フライパンに1cm程度の油を熱し、中火で片面3分ずつ揚げ焼きにする
4. レモンを添えて

### R16 鶏むねの南蛮漬け
**2食分 / P 約33g / 20分 / 冷蔵3日**

材料：鶏むね肉 300g、玉ねぎ 1/2個、にんじん 1/3本、片栗粉 大さじ2、油 大さじ2
南蛮酢：酢 大さじ4、醤油 大さじ3、砂糖 大さじ2、水 大さじ2、鷹の爪 少々

1. 玉ねぎは薄切り、にんじんは千切りにし、南蛮酢と合わせておく
2. そぎ切りにしたむね肉に片栗粉をまぶし、多めの油で揚げ焼き
3. 熱いうちに南蛮酢に漬ける。冷蔵で味がなじむので作り置き向き

### R17 親子丼
**1食分 / P 約32g / 12分**

材料：鶏もも肉 120g、玉ねぎ 1/4個、卵 2個、ごはん 200g
煮汁：水 80ml、めんつゆ（2倍）大さじ3、砂糖 小さじ1

1. 小さめの鍋に煮汁と薄切り玉ねぎ・一口大の鶏肉を入れ、中火で5分煮る
2. 溶き卵の2/3を回し入れ、半熟になったら残りを入れて火を止め、蓋をして30秒
3. ごはんにのせる。三つ葉やねぎがあれば

### R18 鶏ももと大根の煮物
**2食分 / P 約27g / 25分**

材料：鶏もも肉 300g、大根 1/3本、ゆで卵 2個（R02を流用可）、水 300ml
調味料：醤油 大さじ3、みりん 大さじ3、砂糖 大さじ1、酒 大さじ2、生姜（薄切り）少々

1. 大根は2cm厚のいちょう切り。耐熱容器に入れラップしてレンジ5分（下茹でを時短）
2. 鍋で鶏肉の皮目を焼き、大根・水・調味料を入れて落とし蓋をし中火15分
3. ゆで卵を入れて5分煮る

### R19 手羽元と卵のさっぱり煮
**2食分 / P 約35g / 30分 / 冷蔵4日**

材料：鶏手羽元 8本、ゆで卵 4個
煮汁：酢 100ml、醤油 100ml、砂糖 大さじ3、水 100ml、にんにく 1片

1. 鍋に煮汁と手羽元を入れ、強火で沸騰させる
2. 弱めの中火にして蓋をし、時々転がしながら20分煮る
3. ゆで卵を加え、煮汁を絡めながら5分。酢の効果で骨からほろっと外れる

### R20 鶏団子鍋
**1食分（〆込み）/ P 約36g / 20分**

鶏団子：鶏ひき肉 150g、片栗粉 小さじ2、おろし生姜 小さじ1/2、塩 少々、ねぎ（みじん）少々
具：絹豆腐 150g、白菜 2〜3枚（キャベツでも）、しめじ 1/2袋、にんじん少々
スープ：水 400ml、鶏がらスープの素 小さじ2、醤油 小さじ1、塩 少々（または市販の鍋つゆ、乳成分の有無を確認）

1. 鶏団子の材料をポリ袋でよく揉む
2. 鍋でスープを沸かし、袋の角を切って団子を絞り落とす
3. 野菜・豆腐を入れて10分煮る
4. 〆：ごはん＋溶き卵で雑炊（P+6g）

### R21 鶏ひき肉と豆腐のハンバーグ
**2食分 / P 約26g / 20分 / 冷凍2週間**

材料：鶏ひき肉 200g、木綿豆腐 150g、卵 1個、片栗粉 大さじ2、玉ねぎ 1/4個（みじん）、塩こしょう、油 少々
和風ソース：醤油・みりん 各大さじ2、砂糖 小さじ1、大根おろし（あれば）

1. 豆腐はキッチンペーパーで包みレンジ2分→水切り
2. 全材料をよく混ぜて4等分し小判型に。**パン粉・牛乳の代わりに豆腐＋片栗粉でつなぐ**
3. 中火で焼き色をつけ、裏返して蓋をし弱火6分
4. ソースを入れて絡める

### R22 鶏むねとキャベツの塩昆布レンジ蒸し
**1食分 / P 約34g / 10分**

材料：鶏むね肉 150g、キャベツ 2枚、塩昆布 大さじ1、酒 大さじ1、ごま油 小さじ1

1. キャベツはざく切り、むね肉はそぎ切り
2. 耐熱容器にキャベツ→鶏肉→塩昆布・酒をのせ、ラップしてレンジ5分
3. ごま油をかけて混ぜる。洗い物が少ない時短メニュー

## 主菜：豚肉

### R23 豚こまとキャベツの生姜焼き
**1食分 / P 約28g / 12分**

材料：豚こま肉 150g、キャベツ 2枚、玉ねぎ 1/4個、片栗粉 小さじ1、油 小さじ1
タレ：醤油・酒・みりん 各大さじ1、おろし生姜 小さじ1、砂糖 小さじ1/2

1. 豚こまに片栗粉をまぶす（タレが絡んで柔らかくなる）
2. 油で玉ねぎと豚肉を炒め、肉の色が変わったらざく切りキャベツを加える
3. タレを入れて汁気がなくなるまで炒める

### R24 麻婆豆腐
**2食分 / P 約25g / 15分**

材料：木綿豆腐 1丁（350g）、豚ひき肉 150g、長ねぎ 1/2本、おろしにんにく・生姜 各小さじ1、豆板醤 小さじ1〜2、ごま油 大さじ1
