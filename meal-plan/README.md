# 高たんぱく・節約・時短 献立プラン（乳製品・チーズ・ピーマンなし）

筋肉をつけたい人向けに、**安い食材で、たんぱく質をしっかり、手間少なめ**で作れる献立です。

## 基本方針

- **1人分**で計算（作り置きは2〜4食分まとめて作る）
- 1日のたんぱく質目標：**約100〜130g**（体重60〜70kgで「体重×1.6〜2g」の目安）
- 主なたんぱく源：鶏むね肉・鶏もも肉・豚こま・ひき肉・卵・納豆・豆腐・厚揚げ・ツナ缶・サバ缶・鮭
- 調理時間：平日は**15〜20分以内**、作り置きは週末に約60〜90分
- 食費の目安：**1週間 約6,000〜8,000円**（米・調味料を除く、地域・時期で変動）

## 避ける食材

| 避ける | 代わりに使うもの |
|---|---|
| チーズ・牛乳・ヨーグルト・バター・生クリーム | 豆乳（大豆製品なので乳製品ではない）、サラダ油・ごま油・オリーブ油 |
| ピーマン | キャベツ・玉ねぎ・にんじん・ブロッコリー・小松菜・ニラ・もやし |
| ホエイプロテイン（乳由来） | ソイプロテイン（使う場合） |

### 乳成分が隠れていやすい市販品（原材料表示をチェック）

- **カレールウ・シチュールウ** → 本プランでは**カレー粉＋トマト缶**で代用
- 食パン・ロールパン・菓子パン（脱脂粉乳・バター入りが多い） → 本プランは**ごはん中心**
- マーガリン、一部のドレッシング、コンソメ・鶏がらスープの素の一部、ハム・ソーセージの一部
- ※**卵・マヨネーズは乳製品ではない**ので使用しています

## 1日のたんぱく質を稼ぐコツ

1. **毎食「手のひら1枚分」の肉・魚＋卵か大豆製品**をセットにする
2. 朝は「納豆＋卵」で手軽に約14g確保
3. 間食に**ゆで卵・煮卵・サバ缶・ツナ缶・豆乳**（1回10〜20g）
4. 鶏むね肉は**特売日に2kgまとめ買い→下味冷凍**すると最安＆時短
